## Hosting and server log files

This website is hosted on GitHub Pages. When you visit it, the hoster processes the following data, which your browser transmits:

* IP address
* the address of the previously visited page (referrer)
* date and time of the request
* content of the request and HTTP status code
* amount of data transferred
* browser and operating system information

This is necessary to deliver the website and to ensure its stability and security. The legal basis is our legitimate interest according to Art. 6 (1) lit. f GDPR in providing the website without operating our own server.
